## Summary

Understanding how our visual system processes information, the shortcuts it takes, and the interesting effects this can cause, is fundamental to our being able to put together successful data visualisations. Much work has been done to understand how we might represent data in a visual form, and to empirically understand which of these representations are most effective for representing different types of data, and for different purposes. 

With this knowledge, we can move forward and start to consider how we might combine visual representations of data into actual visualisations, and the sorts of types of visualisation we can use in different scenarios.
