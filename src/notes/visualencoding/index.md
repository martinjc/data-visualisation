# Visual encoding

The human visual system is the evolutionary result of a world in which survival depends on being able to rapidly process visual information to detect, identify and track both predators and prey. That this system also allows us to interpret and understand more abstract types of visual information, such as graphs, is somewhat coincidental. 

Our job, as data visualisation designers, is to work within the constraints of this system to encode data in a way that is as easily understood as possible. When the visual encodings we use are wrong and work against the cognitive mechanisms within our visual processing systems, we create confusion and misunderstanding, rather than clarity and insight.

In order to create effective visualisations that are processed and understood quickly and accurately, we need to understand how our visual system processes visual information. This includes understanding the fundamental visual variables that we can use to encode data, as well as the way that these variables are processed by our visual system. Through the work of Jacques Bertin we have a good understanding of the fundamental visual variables, and through the work of Gestalt psychologists we have a good understanding of how our visual system processes visual information. Experimental data has been collected on the effectiveness of different visual encodings, and this data has been used to create rankings of visual encodings based on their effectiveness. All this means that with an understanding of the ways in which humans perceive, group and understand visual representations of data, we can ensure we are creating effective data visualisations that work *with* our visual systems, not against them.
